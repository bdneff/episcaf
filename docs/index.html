Epitope Scaffolder

Given an antibody–antigen complex, design protein scaffolds that present the epitope in its native, antibody-binding conformation. Pipeline: RFdiffusion → backbone pre-filter → ProteinMPNN → AlphaFold3 → scoring.

Prototype. Runs are simulated using the project's real DP4 enrichment rates; the selected structure is shown in an interactive 3D view of the real PDB (drag to rotate). The page does not compute — it prints the Gemini job it would submit. Live routing needs the backend service (see bottom). Per-row design metrics except #1 are illustrative.

The job this run maps to. The page cannot submit it; run it on Gemini, or have a backend service post this spec to the cluster.


  

  
How this becomes a real server. This page is a static frontend — it runs the same whether served from GitHub Pages or opened locally. To route a job to Gemini it would call a small backend API (FastAPI/Flask) on a cluster-access host, which submits RFdiffusion → backbone pre-filter → ProteinMPNN → AlphaFold3 and reports back. runJob() in this page can swap its simulated result for a fetch() to that API.
