Next-generation methods

Three methods from John Altin’s 2026-11-03 reports (AOMclash revised 8-Nov, with a 4-Nov island-order bug fix), each backed by a reference implementation (R + Python on Tamarind / AF2), being ported into episcaf_v2 (Python / Gemini / AF3).

AOMclashlearned clash predictorin progress

Replaces the geometric native-aware cylinder with a gradient-boosted regressor that reads an antibody occupancy map (built from 1,036 SAbDab complexes) at each scaffold atom. Antibody-geometry only, so the map is AlphaFold-version agnostic; we retrain the regressor on our AF3 clash labels.

  • ✓1a · Get the code. Fetched upstream/feat/aomclash; read the map builder + feature extractor.
  • ✓1b · Reproduce the occupancy map. Rebuilt from 944 local SAbDab complexes; matches John’s Fig 4 (peak 0.956 vs 0.94; radial bands exact).
  • ✓1c · Port feature extraction. All 111 model inputs ported (105 design_feats + 6 target_features, cylinder counts now among them) — byte-for-byte identical to John’s design_feats on a synthetic design, with a durable test suite tying the cylinder back to native_cylinder_core. Already order-safe, so John’s 4-Nov island-order fix lands in the loader, not the feature math.
  • ●1d · Retrain on AF3 labels. Next: a cluster loader builds features from our AF3 structures (threading each design’s own island order), then HistGBR on af3_n_clash_res with leave-one-epitope-out folds, matching John’s revised 8-Nov report.
  •  1e · Ship the scorer. John now ships aom_score.py + a trained (AF2) model upstream; we port that harness, wire aomclash_pred into stage05/06, and swap it into the twelvemer preset.
  •  1f · Docs + manuscript. Cylinder → learned-model section, figures, FIGURES.md.
growPatchno-antibody epitope enumerationplanned

The second input mode: grow footprint-sized surface patches (relSASA seed → greedy grow to ~16 residues → gap-fill → ≤3 islands → Jaccard NMS) so every possible epitope is represented, then rank the ~54 patches/antigen by a learned likelihood instead of geometry alone. Replaces the old tiled-12mer no-antibody approach.

  •  Port segmentation/growPatch.py as a Python module.
  •  Learned ranking tweak (DiscoTope-3.0 is already baked into the GUI’s predict mode).
IPD loopiterative generationplanned

The generation loop that wraps the whole middle of the pipeline: an RFD3 backbone pre-filter (using AOMclash), escalating de-novo → seeded rounds, partial-diffusion children, randomized island order, and a composite stopping rule.

  •  Open question first: the partial-diffusion intuition — exploration vs exploitation, and whether it finds genuinely better designs or just best-of-N in a good neighborhood (John’s own false-discovery caveat). This sets the children-vs-de-novo budget.
  •  Port efficientScaffolding/tamarind.R into the Python/Gemini/AF3 pipeline.
★ Current focus: AOMclash — reconciled our port with John’s 8-Nov report and 4-Nov bug fix (the feature extractor already matches his 111 inputs and is island-order safe). Next is step 1d: the cluster-side loader to build features from our AF3 structures, then retraining the regressor on AF3 clash labels with leave-one-epitope-out folds.
