Configure scaffold design

Define the epitope from an antibody–antigen complex or select antigen residues directly. Configure backbone generation, sequence design, structure prediction, and ranking below.

Without a connected service, this page simulates a run. With a service and an uploaded structure, it prepares design inputs and a cluster submission script; cluster calculations begin when that script is submitted. The structure viewer displays the selected example or uploaded file, and changing protocol settings does not rerun a recorded example.

Design protocol

Configure the design steps below. The simulation and submission-script preview update with the supported settings.

1 Generate backbones — RFdiffusion3

RFdiffusion3 generates de novo backbones — the scaffold’s 3D shape, before any amino-acid sequence is assigned — that hold the epitope in its native geometry.

Number of candidate backbones requested for each epitope. Each retained backbone proceeds to sequence design.
0.00
Planned setting. Helix bias is not connected to the current generation workflow.
Use selected designs from one round to generate variants for the next round. Each round also includes independently generated backbones. How the loop works ›
Upper limit on the number of rounds. An epitope can stop earlier under the configured improvement criterion.
2 Backbone obstruction filter

AOMclash estimates whether a generated backbone could obstruct antibody binding. Candidates with lower obstruction scores are prioritized before sequence design.

Uses AOMclash to estimate obstruction from an antibody-occupancy map, before sequence design (ProteinMPNN) and structure prediction (AlphaFold 3). AOMclash calculation and validation ›
Backbones are ranked separately for each epitope by AOMclash score (s_p1_free; lower is less obstruction). The selected percentage with the lowest scores continues to ProteinMPNN and AlphaFold 3; the rest are discarded.
%
3 Design sequences — ProteinMPNN

ProteinMPNN assigns an amino-acid sequence to each kept backbone, holding the epitope positions fixed so the epitope keeps its native identity while the rest of the scaffold is free.

Number of sequence candidates generated for each retained backbone. Each sequence is evaluated by structure prediction.
4 Predict structure — AlphaFold3

AlphaFold 3 predicts a structure for each sequence. The predicted structure is compared with the intended design and reference epitope. Single-sequence input (a self-only MSA); templates disabled; seed 1.

5 Design ranking and selection
Choose the score used to rank the predicted designs. Model definitions and evaluation results are available in the linked documentation. Default: logistic regression, based on the documented validation comparison.
